# Memorycore Future Roadmap

The first version remains intentionally small: SQLite, `MemoryService`, FTS5, MCP, CLI, and tests.

Later phases may add:

1. Write-candidate approval, provenance, corrections, supersession, audit, duplicate detection, and contradiction handling.
2. Embeddings, semantic retrieval, hybrid ranking, reranking, caching, and retrieval benchmarks.
3. Entity graphs, graph traversal, temporal links, and an optional CozoDB adapter.
4. PostgreSQL, synchronization, remote deployment, import/export, Obsidian, browser, and messaging integrations.
5. User and agent identities, scopes, policy controls, and approval interfaces.
6. Mojo components, learned-memory engines, background consolidation, and other experiments.

Future features must remain optional unless they are proven necessary, preserve inspectability and exportability, and include tests.
